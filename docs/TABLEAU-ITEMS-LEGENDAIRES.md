# Tableau des items légendaires CobbleLore

Namespace : `cobblelore:<id>`. Mod **cobblelore-legendary** (98 items).

**Spawn monde** = tu portes l’item + conditions (biome, etc.) → le jeu peut faire apparaître le Pokémon (addon Myths and Legends + datapack sur le serveur).

**Monument (pedestal)** = tu trouves la structure Legendary Monuments + tu poses l’item sur le pedestal (~20 espèces).

**Doublon** = deux items pour le même Pokémon ; un seul sert en général au **spawn monde** (colonne *canon*).
